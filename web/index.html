03 / READ THE EVIDENCE

A record of reporting,
not an uptime score.

These are the providers’ public statements. Incident counts cannot rank service reliability: products, reporting practices and feed windows differ. A quiet feed is not evidence of uninterrupted service.

We fetch six public API responses once a day, retain the latest 90 successful captures and keep earlier event text in those captures. A failed collection leaves the previous published capture intact. GitHub schedules can run late; check collection time before relying on a record.

Dates, gaps & privacy

  • Collection time is when CoolCode saved the responses. Each endpoint has its own retrieval time.
  • Reported update and event dates come from the provider and may be revised.
  • Missing later means absent from that response, never automatically resolved. Providers expose a limited recent window.
  • Filters stay in this browser. No account or API key is needed. Downloads contain public provider data. CoolCode’s standard visit counter also loads.
